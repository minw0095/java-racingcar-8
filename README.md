# java-racingcar-precourse



### 기능 요구 사항 분석



#### 입력 받기

1. 이름 입력

   * 쉼표(,)를 기준으로 구분
   * 이름은 5자 이하 -> myname(x), name(o)
     - 5자가 넘어갈 경우 예외 발생

   

2. 이동 횟수 입력

   * 전진 or 정지를 몇 번 진행 할 것인지 숫자를 입력 받음
     - 숫자가 아닐 경우 예외 발생
     - 1 보다 작은 숫자 일 경우 예외 발생



#### 경주

1. 입력 받은 횟수에 따라 각 자동차는 전진 or 정지

   * 0에서 9 사이에서 무작위 값을 받음

     * pickNumberInRange()를 활용

   * 무작위 값이 4이상 일 경우 전진, 그 이외의 수는 정지

   * 경주의 진행도를 '-'를 통해서 나타낸다

     ex)

     ```
     pobi : - 
     woni : 
     jun : - 
     
     pobi : --
     woni : - 
     jun : --
     ```

   * 우승자는 한 명 이상으로 출력

     * ex) 최종 우승자 : pobi, jun
